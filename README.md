Mystery Files

Created by Cassie Nguyen

Project Description

Mystery Files is a mystery investigation website where players can explore different cases and try to solve them. I chose Track C: Mystery Files and the Investigation Pack for my project. There are three cases, and each one has its own story, suspects, evidence, and investigation question. The goal is to look through the information and figure out who is responsible.

Setup and Navigation

To start, open index.html . The starting page has a Start button and a Credits button. 

Clicking Start takes you to the homepage where you can expand the Game Rules to read them. 

From there, you can choose between three different cases. Each case has its own description, suspects, evidence, investigation, and a answer to the case.

Features and Proposal Requirements

For the Mystery Files track, I made three different cases for players to investigate. Each case has suspects with their own dialogue and pictures, along with evidence that helps the player figure out the answer. Players can look through the information in any order before making their choice.

For the Investigation Pack, I added expandable clue cards and evidence status markers. The clues start as Not Reviewed and change to Reviewed when opened. This lets players reveal the evidence one clue at a time instead of having everything shown at once.

For the investigation questions, I used radio buttons to let players choose their answer. If the answer is wrong, a message appears telling them to try again. If they choose the correct answer, the Solve Case button appears and takes them back to the homepage.

Design Decisions

I wanted the website to be simple and easy to navigate, so I used expandable sections for the rules, suspects, and evidence. When you click on a suspect, their picture and dialogue appear. I also added a button to close out of the dialogue, which brings you back to the case page.

I used the same CSS file for all the pages so the design would stay consistent. I also added hover effects and animations to make the buttons, sections, and suspect dialogues more interactive.
